# Sealcode

Confidential AI coding, with receipts. A gateway that lets regulated engineering teams use Claude
Code, OpenCode, Cline and Continue with open models running inside hardware enclaves on Phala.

Work in progress. See [docs/BRIEF.md](docs/BRIEF.md) for the product brief,
[docs/spike-report.md](docs/spike-report.md) for the Phase 0 findings and
[CLAUDE.md](CLAUDE.md) for development commands.
